# 架构说明

## 设计原则

该系统面向约 5 人的内部 IIT 项目团队，优先降低填报和运维成本，不为尚未出现的规模预先引入分布式架构。

## 组件

- Web：React + Ant Design，提供项目组合、项目工作台、里程碑和个人事项视图。
- API：NestJS，统一处理登录会话、业务校验、导入、附件和审计记录。
- 实时刷新：Socket.IO 在数据修改后通知其他页面，5 秒轻量轮询作为网络中间层阻断 WebSocket 时的兜底。
- 数据：SQLite 保存项目结构化数据，附件保存在服务器本地目录。
- 部署：单台 Ubuntu 服务器，systemd 托管 Node.js 进程，Caddy 提供反向代理。

## 一次读取，统一刷新

首页使用聚合快照接口获取项目、里程碑、目标、预算和事项，避免按项目逐个请求导致的加载等待。任一修改完成后，后端发布 `project.changed` 事件，前端将相关查询标记为过期并重新获取。

## 可接受的取舍

- SQLite 和单服务器足以支撑当前团队，但不面向大规模多租户。
- 内部共享密码使入门简单，但无法提供精细的账号权限和离职回收。
- 本地附件目录易于运维，备份时必须同时备份 SQLite 和附件目录。
- 系统只保存项目管理数据，不应存储受试者个人信息或临床原始数据。
